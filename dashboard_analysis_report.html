信号：红柱扩张 → 多头动能延续

通俗解释：DMI 是"趋势强度检测器"。+DI 代表多头力量，-DI 代表空头力量。ADX 才是关键——它不告诉你方向，只告诉你趋势有多强：ADX > 25 = 有明确趋势；ADX > 50 = 超强趋势；ADX < 20 = 没有趋势（震荡市）。就像开车时看速度表——ADX 告诉你开得多快，+DI/-DI 告诉你朝哪个方向开。

OBV

五、仪表盘展示优化建议（10 项）

1. 增加 K 线图（蜡烛图）模式 高优先级

当前主图仅用折线图展示收盘价，缺少开盘价/最高价/最低价的视觉信息。K 线图是黄金交易最基础的分析工具——红色阳线代表当日收涨，绿色阴线代表收跌，上下影线展示日内波动范围。建议在主图增加 K 线/折线切换按钮，ECharts 原生支持 candlestick 类型。

2. 共识仪表盘增加数值显示 高优先级

当前共识仪表盘（gauge）只有弧线可视化，没有在表盘上直接显示 +0.66 这个数值。用户必须看旁边的文字才能知道具体分数。建议在仪表盘中心叠加显示 "0.66" 数值，一目了然。

3. 图表分析面板支持自动刷新 高优先级

当前"图表分析面板"（均线诊断、MACD 动能诊断等文字面板）只在点击信号标记时更新，不会随行情刷新自动更新。建议将分析面板的更新与图表刷新周期绑定，每次刷新数据时同步更新诊断文案。

4. MACD 副图增加关闭开关 中优先级

当前 MACD 副图被硬编码为始终显示（const showMACD = true; // 始终激活副图），其他指标均可切换。建议统一为可切换，当用户选择 DMI 或 ROC 时可以隐藏 MACD 副图以节省屏幕空间。

5. 增加量价背离实时预警 中优先级

当前 OBV 子评分 -21 已检测到量价背离，但前端没有醒目提示。建议在共识面板中当任意子指标为负值（尤其是 OBV）时，在该指标条上叠加闪烁预警标记 + tooltip 解释"价格上涨但资金未配合，警惕虚涨"。

6. 增加超买/超卖区域背景着色 中优先级

RSI、KDJ、W&R 等震荡指标的副图当前只有参考线（如 70/30 线），建议在超买区（>70）背景填充浅红色透明区域，超卖区（<30）填充浅绿色透明区域，让用户一眼看出当前处于什么区域。

7. 预测区间宽度可视化 中优先级

当前预测的上轨/下轨虽然有面积填充，但没有直观展示"不确定性在扩大"。建议在预测区域下方叠加一个"置信度衰减条"——从左到右颜色从绿到红渐变，直观传达"越往后越不准"的信息。

8. 增加价格提醒/价格预警功能 低优先级

当前仪表盘展示实时价格但无预警机制。建议增加可配置的价格提醒（如"跌破 950 时弹窗提醒"），前端用 localStorage 存储阈值，行情刷新时检测是否触发。

9. 增加更多时间周期选项 低优先级

当前仅支持 15M / 1H / 日线 三个周期，缺少 4H 和周线。4H 是黄金日内交易最常用的周期之一，建议在东方财富 K 线接口 klt 参数中增加 4H 映射（klt=1 或自定义）。

10. CR 指标数据窗口自适应 低优先级

CR 需要 26 日数据，但 7 天图表只有 7~9 个数据点导致 CR 为 None。建议后端在数据点不足时自动延长内部抓取范围（如取 30 天数据来计算 CR），而非直接返回 None。

六、策略与风控优化建议（6 项）

1. 增加"极端乖离"前端醒目提示

共识评分代码已有极端乖离判断逻辑（布林带偏离 > 1.2 倍带宽 + ADX > 45 时降级 50%），但当前 ADX 64.25 已远超 45 阈值。建议前端在极端乖离触发时，在评级标签旁显示醒目的 ⚠️ 警示图标，并附带解释文案"强趋势末端，历史回测中此状态后常出现超买/超卖反弹"。

2. OBV 量价背离应影响开仓建议

当前 OBV 子评分 -21 是唯一偏空信号，但系统建议文案仍然输出"轻仓顺势做多"。建议策略引擎在 OBV 为负且绝对值 > 20 时，在建议文案中追加"量价背离警示：当前上涨缺乏资金配合，建议减小开仓规模或等待回调"。

3. KDJ 即将死叉加入预警

当前 KDJ K=80.39 < D=83.53，J=74.11 已回落。虽然尚未形成正式死叉，但趋势已明确。建议在 K < D 且 J < K 的"准死叉"状态时，在共识面板的 KDJ 条上显示黄色闪烁标记，提示"即将死叉"。

4. 多周期共振确认机制

当前共识评分仅基于单一周期（日线）。建议增加多周期共振检查——同时拉取 1H 和 15M 的共识评分，如果三个周期方向一致（如日线 + 1H + 15M 均偏多），在仪表盘上显示"三周期共振"徽章，提高信号置信度。

5. 自动交易增加"超买不开新仓"保护

当前自动交易规则中，"极端乖离"会禁止开新仓（代码已实现），但 RSI > 70 超买时仍允许开多。建议在 decide_action() 函数中增加 RSI > 75 时禁止开新多仓的逻辑，避免在超买区域追高。

6. 预测模型增加"宏观事件日历"叠加

Holt 模型纯统计外推，最大缺陷是不考虑宏观事件。建议在前端预测区间上叠加近期重要宏观事件标记（如美联储 FOMC、CPI 发布日），提醒用户这些日期前后预测误差可能极大。数据可静态维护在 JSON 中，无需实时抓取。
